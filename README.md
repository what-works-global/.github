# .github

Organisation profile, brand assets and default community health files for [What Works](https://github.com/what-works-global).

- `profile/README.md` — the profile shown at [github.com/what-works-global](https://github.com/what-works-global)
- `profile/assets/` — hero and theme-aware mark used by the profile
- `assets/` — source brand marks (wordmark and w-block-w)
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` — org-wide defaults, used by any repository that doesn't have its own
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` — default issue forms and PR template for repositories without their own
