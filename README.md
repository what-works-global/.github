# .github

Organisation profile, brand assets and default community health files for [What Works](https://github.com/what-works-global).

- `profile/README.md` — the profile shown at [github.com/what-works-global](https://github.com/what-works-global)
- `profile/assets/` — hero and theme-aware mark used by the profile
- `assets/` — source brand marks (wordmark and w-block-w)

## No default community health files — on purpose

GitHub applies anything named `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, or an issue/PR template, from this repository to **every** repository in the organisation that lacks its own, public or private alike. Most of our repositories are private client sites forked from a template, and showing them an open-source contributing guide and code of conduct was noise. So this repository holds none of those files.

Each public repository carries its own instead — see [payload-packages](https://github.com/what-works-global/payload-packages) (`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, issue forms, PR template). Don't add defaults back here without a plan for the private repositories.
