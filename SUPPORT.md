# Getting help

Our open-source projects are maintained by a small team alongside our day-to-day work. Here's where to go so your question reaches the right place.

| You want to… | Go to |
| --- | --- |
| Ask how to use something, or float an idea | The repository's **Discussions** tab, if it has one (for example [payload-packages](https://github.com/what-works-global/payload-packages/discussions)) |
| Report a bug | An **issue** using the bug report form. See [CONTRIBUTING.md](CONTRIBUTING.md#reporting-a-bug) for what makes a report useful |
| Request a feature | An **issue** using the feature request form, or a discussion if it's still a rough idea |
| Report a security vulnerability | **Not a public issue.** Follow [SECURITY.md](SECURITY.md) |
| Get help with Payload, Next.js or another upstream framework | That project's own docs and community, e.g. [Payload docs](https://payloadcms.com/docs) |

Before posting, it's worth checking the package README and searching existing issues and discussions. Someone may already have asked.

We answer as time allows and can't promise response times on community support. For paid work with What Works, see [whatworks.com.au](https://whatworks.com.au).
