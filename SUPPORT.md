# Getting help

Where to go so your question reaches the right place.

## Open-source packages and tools

Maintained by a small team alongside our day-to-day work, so we answer as time allows and can't promise response times.

| You want to…                                                     | Go to                                                                                                                                              |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ask how to use something, or float an idea                       | The repository's **Discussions** tab, if it has one (for example [payload-packages](https://github.com/what-works-global/payload-packages/discussions)) |
| Report a bug                                                     | An **issue** using the bug report form. See [CONTRIBUTING.md](CONTRIBUTING.md) for what makes a report useful                                      |
| Request a feature                                                | An **issue** using the feature request form, or a discussion if it's still a rough idea                                                            |
| Report a security vulnerability                                  | **Not a public issue.** Follow [SECURITY.md](SECURITY.md)                                                                                          |
| Get help with Payload, Next.js or another upstream framework     | That project's own docs and community, e.g. [Payload docs](https://payloadcms.com/docs)                                                            |

Before posting, check the package README and search existing issues and discussions.

## Client websites and internal projects

If you're a client or a collaborator on one of our private repositories, the project's README names its environments and the What Works team looking after it. Contact them directly, or email [dev@whatworks.com.au](mailto:dev@whatworks.com.au). Security issues follow [SECURITY.md](SECURITY.md) regardless.
