We're **What Works** — a transformation & creative growth company from Australia, working out of Brisbane, Canberra and Sydney. Businesses bring us hard problems; we cut the BS, find what actually works — across brand, growth, product and AI — and deliver it.

A lot of that ends up as software. This is where the engineering side lives: the products and platforms behind our client work, and the open source we put back.

## How we build

What actually recurs across our repos:

- **Web** — Next.js · React · TypeScript · Tailwind CSS
- **Payload CMS** — home ground: most of our sites and platforms run on Payload 3, backed by our own starter kit and plugin suite
- **Backends** — Node.js · Python (FastAPI, Django) · PHP (Laravel) · typed APIs with tRPC, REST & GraphQL
- **AI** — production LLM systems on OpenAI, Anthropic and AWS Bedrock: RAG, vector search, durable workflows with Temporal
- **Mobile** — Flutter · Kotlin Multiplatform · native iOS & Android
- **Creative development** — GSAP · Motion · Lenis · Three.js · D3
- **Infrastructure** — Vercel · AWS · Docker · Kubernetes & Helm · Terraform · GitHub Actions

Plus headless WordPress, Algolia search and realtime services where they're the right call.

## Payload & open source

We build on open source all day, so we put useful pieces back.

Most of what we ship runs on [Payload](https://payloadcms.com), and we kept rebuilding the same things — so we turned them into a plugin suite we maintain in the open:

**[payload-packages](https://github.com/what-works-global/payload-packages)** — thirteen plugins, fields and utilities for Payload 3, built for and reused across our production work. Among them:

| Package | What it does |
| --- | --- |
| `rbac` | Role-based access control with a permissions matrix |
| `activity-log` | Chronological event tracking across collections and globals |
| `algolia-search` | Algolia sync with draft awareness and admin reindexing |
| `redirects` | Redirect management wired into Next.js middleware |
| `audit-fields` | createdBy / lastModifiedBy on everything |
| `sitemap` | Cached XML sitemap generation |

Building on Payload? Have a dig around — issues and PRs welcome.
