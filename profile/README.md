## Payload & open source

We build on open source all day, so we put useful pieces back.

Most of what we ship runs on [Payload](https://payloadcms.com), and we kept rebuilding the same things — so we turned them into a plugin suite we maintain in the open:

**[payload-packages](https://github.com/what-works-global/payload-packages)** — thirteen plugins, fields and utilities for Payload 3. Among them:

| Package | What it does |
| --- | --- |
| `rbac` | Role-based access control with a permissions matrix |
| `activity-log` | Chronological event tracking across collections and globals |
| `algolia-search` | Algolia sync with draft awareness and admin reindexing |
| `redirects` | Redirect management wired into Next.js middleware |
| `audit-fields` | createdBy / lastModifiedBy on everything |
| `sitemap` | Cached XML sitemap generation |

Building on Payload? Have a dig around — issues and PRs welcome.
